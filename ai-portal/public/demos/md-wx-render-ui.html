微信公众号 Markdown 渲染组件

这是一个专为微信公众号排版优化的 Markdown 渲染组件，支持实时预览、主题切换和一键复制功能。

✨ 核心功能

  • 实时渲染：支持 Markdown 到 HTML 的实时转换
  • 主题切换：提供5种精心设计的视觉主题
  • 响应式视图：手机/桌面两种预览模式
  • 一键复制：完美适配微信公众号格式

🎨 主题展示

点击顶部 🌈 主题切换 按钮，体验现代设计趋势：

基于2025年UI设计趋势，融合极简主义、自然元素、赛博风格、优雅配色和温暖色调，每种主题都精心调配。

const renderMarkdown = (content, theme) => { const html = parseMarkdown(content); const styledHtml = applyTheme(html, theme); return convertToWechatFormat(styledHtml); };

📱 响应式设计

支持手机视图和桌面视图两种模式，点击顶部 📱💻 按钮即可切换：

  • 手机视图：375px 宽度，模拟真实手机显示效果
  • 桌面视图：自适应宽度，适合大屏幕编辑

🚀 使用说明

  1. 在左侧编辑器中输入 Markdown 内容
  2. 选择合适的主题和视图模式
  3. 点击 📋 复制按钮，将内容粘贴到微信公众号
  4. 享受完美的排版效果！
