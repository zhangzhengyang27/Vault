01. 新一代模型概览

Anthropic 推出了全新的 Claude 4 系列模型，重新定义了编码、推理和 AI Agent 的标准。

Hybrid 混合架构模式

即时响应模式 + 扩展思维模式 (Extended Thinking)

双模型发布

Claude Opus 4（旗舰版）与 Claude Sonnet 4（升级版）同步登场，覆盖从日常任务到极端复杂场景的全方位需求。

广泛的可用性

支持 Web 端、API、Amazon Bedrock 及 Google Cloud Vertex AI。Sonnet 4 同时面向免费用户开放。

一致的定价策略

Opus 4: $15/$75 (输入/输出 每百万 token)
Sonnet 4: $3/$15 (输入/输出 每百万 token)

04. Agent API 新能力

Anthropic 发布了四项全新的 API 能力，赋能开发者构建更强大的 AI Agent。

Power 四大核心工具

代码执行工具 (Code Execution)

允许模型在安全沙箱环境中编写和运行 Python 代码，用于高级数据分析和计算。

MCP 连接器 & Files API

支持通过 Model Context Protocol 连接外部系统，并能跨会话高效存储和访问文件。

Prompt 缓存 (Prompt Caching)

支持长达 1 小时的 Prompt 缓存，大幅降低长上下文任务的成本并提升响应速度。

05. 扩展思维与记忆

通过工具使用和本地记忆能力，Claude 现在能够像人类一样进行更深层次的思考和连续工作。

Smart 自主进化

扩展思维 (Extended Thinking)

模型可以在思考过程中交替使用工具（如网络搜索），并在回复前进行更深度的推理。

并行工具使用

支持同时并行调用多个工具，显著提升复杂任务的处理效率。

本地文件记忆

当被授予本地文件访问权限时，能提取并保存关键事实，构建隐性知识，保持工作连续性。
