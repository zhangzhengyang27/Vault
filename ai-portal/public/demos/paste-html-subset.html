富文本粘贴转 HTML 子集

支持的 HTML 元素

  • p - 段落
  • strong - 粗体文本
  • em - 斜体文本
  • blockquote - 引用文本
  • code - 代码片段
  • a - 链接(href 属性保留)
  • h1-h6 - 标题
  • ul - 无序列表
  • ol - 有序列表
  • li - 列表项
  • dl - 定义列表
  • dt - 定义术语
  • dd - 定义描述

使用 Ctrl+V 或 ⌘+V 粘贴以捕获富文本 HTML。移动端请在长按菜单中选择「粘贴为带格式文本」。
