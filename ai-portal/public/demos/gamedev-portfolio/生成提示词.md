# PR0TO::DEV 独立游戏开发者作品集 — 完整需求提示词

> 本文件是生成 `index.html` / `styles.css` / `app.js` 的完整提示词，整合初始需求、确认过的决策与实现细节。
> 可直接作为独立 prompt 复现本项目，也可作为后续维护的依据。

---

## 1. 任务目标

生成一个**独立游戏开发者（Indie Game Developer）个人作品集网站**：展示 Steam 已发售游戏、Game Jam 原型与技术博客，塑造「小而锋利」的独立精神。多文件交付（HTML + CSS + JS + assets），纯原生零依赖。

## 2. 需求规格

### 2.1 角色与调性

- 角色：solo 独立游戏开发者，做过上线 Steam 的游戏、多次 Game Jam、写技术博客
- 调性：专业但不端着，带极客/赛博感，突出「小而锋利」的独立精神
- 语言：中文为主、英文点缀（kicker / tag 用英文），双语混排

### 2.2 必须包含的板块（自上而下）

1. **吸顶导航**：品牌 `PR0TO::DEV`（mark 青色 + `::` 品红 + DEV 灰色），锚点链接「游戏 / Game Jam / 博客 / 关于」，移动端折叠为汉堡菜单（含 `aria-expanded` 状态切换）
2. **Hero**（`#top`）：kicker（`/ 独立游戏开发者 · SOLO INDIE DEV`）、大标题「你好，我是 PR0TO_」（名字青→品红渐变 + 闪烁光标）、副文案、双 CTA（看我的游戏 / GitHub 仓库）、4 项数据（2 款 Steam 游戏 / 14 次 Game Jam / 25k+ Steam 愿望单 / 30+ 篇技术博客）、右下 SCROLL 指示器
3. **Steam 游戏**（`#games`）：数据驱动卡片——封面图 + 点击懒加载预告片、发售 badge、meta（平台·类型·评测数）、描述、技术 tag 胶囊、Steam 商店 + 在线试玩 Demo 按钮；偶数卡片左右镜像排版
4. **Game Jam**（`#jam`）：3 张卡片（封面 + 角标 badge + 标题 + 描述 + 技术栈 + 试玩 Demo / 源码 GitHub 链接）
5. **技术博客**（`#blog`）：列表式（日期 / 标题 / 分类 tag / 箭头），标题行右侧「查看全部文章 →」
6. **关于**（`#about`）：左栏介绍文案（含个人经历与日常技术栈）+ 技术栈 chips；右栏 aside 放联系方式（邮箱 / GitHub / Steam / itch.io / Bluesky）+ 接单状态（`STATUS: 接受外包 & 联合开发邀约`）
7. **页脚**：品牌 + 年份 + 一句话注 + BACK TO TOP

## 3. 决策记录

| 决策项 | 选择 | 说明 |

### 4.2 字体 / 节奏

- `--font-display: "Space Grotesk", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`
- `--font-mono: "IBM Plex Mono", "SF Mono", Menlo, Consolas, monospace`
- 缓动：`--ease-out-quart` / `--ease-out-expo`；时长 `--dur-fast 150ms / --dur-med 300ms / --dur-slow 500ms`
- 圆角 `--radius 14px` / `--radius-sm 8px`；容器 `--container 1120px`；正文行长 `--measure 65ch`
- 霓虹光晕：`.hero__glow` 大半径 `blur(90px)` + 低透明度 + `pointer-events:none`

## 5. 交互与动效

- 平滑滚动锚点（`scrollIntoView({behavior:'smooth'})`，`data-scroll` 属性）
- 滚动出现：`IntersectionObserver`（`threshold .12`、`rootMargin 0px 0px -40px`）加 `.is-visible`；无 IO 时兜底全部显示
- 头部描边：滚动 >8px 时 `borderBottomColor` 加深
- 主按钮 hover：背景提亮 + 青色外发光 `box-shadow 0 8px 30px -6px color-mix(cyan)`
- 视频懒加载：`video-btn` 点击后 `replaceChild` 注入 `iframe`（youtube-nocookie + autoplay + rel=0 + allowFullscreen）
- 降级：`@media (prefers-reduced-motion: reduce)` 关闭所有动画/过渡

## 6. 实现要点

### 6.1 数据模型（`app.js` 结构）

**GAMES**（Steam 游戏，2 条：霓虹狂飙 NEON DRIFT / 苍穹拾荒 SKYBOUND）：
`id` / `title` / `badge`（如「已发售 · 好评如潮」）/ `meta`（平台·类型·评测数）/ `desc` / `tags[]` / `image` / `videoId`（YouTube ID）/ `steam` / `demo` / `tagLabel`

**JAMS**（Game Jam 原型，3 条：日光翻转 SOLAR FLIP / 隧道节拍 TUNNEL DRIVE / 迷失森林 LOST FOREST）：
`title` / `badge`（如「LD Jam 54 · Top 10」）/ `desc` / `image` / `demo` / `repo` / `stack`

**POSTS**（技术博客，4 篇：WebGL 2D 光照 / Unity HDRP 性能排查 / Steam 愿望单复盘 / Godot vs Unity）：
`date` / `title` / `tag` / `href`

> 渲染方式：DOM 工具 `el(tag, cls, text)` → `renderGames() / renderJams() / renderPosts()` 注入 `#games-list` / `#jam-list` / `#blog-list`。

### 6.2 工程约束

- 零依赖原生 JS，IIFE `(function(){ "use strict"; ... })()` 封装，DOMContentLoaded 启动
- 数据驱动：内容全在 `GAMES / JAMS / POSTS` 数组，改数据即改页面
- 设计令牌：`styles.css` 顶部 `:root` 定义色彩 / 字体 / 间距 / 动效 / 圆角 / 容器宽
- a11y：`skip-link`、`:focus-visible` 3px 描边、汉堡 `aria-expanded/aria-controls`、视频按钮 `aria-label`
- 响应式：900px（导航折叠、游戏单列、Jam 两列、关于单列、hero 数据两列、隐藏 SCROLL）；600px（Jam 单列、区块收窄、博客单列、hero 按钮全宽）
