同一个模型，不同人用出来的效果天差地别，差距几乎都在提示词（Prompt）上。好消息是：写好提示词不需要任何技术背景，它考验的是"把需求说清楚"的沟通能力。

## 四要素框架

一条合格的提示词，尽量包含这四样东西：

| 要素 | 回答的问题 | 示例 |
| --- | --- | --- |
| 角色 | 你希望它以什么身份思考 | "你是一位资深 HR" |
| 任务 | 具体做什么、产出什么 | "帮我改写这段自我介绍" |
| 约束 | 语气、篇幅、格式、受众 | "200 字内，语气自信不浮夸，面向投行" |
| 示例 | 好的输出长什么样（可选但强大） | 贴一段你满意的旧版本 |

完整示例：

> 你是一位资深 HR（角色）。帮我改写下面的自我介绍（任务），用于投递数据分析师岗位，要求 200 字以内、突出项目量化成果、语气自信但不浮夸（约束）。这是我现在的版本：（贴原文）（示例/素材）

对比"帮我把这个改好一点"——四要素齐了，一次出活的概率会高很多。

## 五个立竿见影的技巧

1. **给材料，别靠回忆**。让模型基于你贴的资料回答，而不是让它猜你的情况。材料越具体，幻觉越少。
2. **给例子，比讲道理管用**。贴 1-2 个你心目中的好答案（few-shot），它模仿得又快又准。
3. **分步骤布置复杂任务**。"先列提纲，我确认后再写全文"——比一次性要终稿质量高得多，也方便中途纠偏。
4. **说清"不要什么"**。"不要空话套话""不要超过三段""不用敬语"这类负面约束，模型遵守得很好。
5. **让它先思考再回答**。难题前加一句"先列出你的分析步骤，再给结论"，准确率会提升——这本质是给了它"打草稿"的空间。

## 迭代：第一次输出只是起点

专业用户和新手最大的差别不是第一条提示词多完美，而是**把对话当草稿台**：

- 输出有一半好用 → "保留前两点，第三点换个角度，整体更口语化"
- 风格不对 → "参考这段话的语气重写"（贴例子）
- 方向跑偏 → 别硬纠，换个更明确的指令重新开始

## 一个心态提醒

模型倾向于讨好你。如果你问"这个方案是不是很棒？"，它大概率顺着你夸。想要真话，就这样问："这个方案有哪些风险和漏洞？请挑剔一点。"**主动邀请批评，是和 AI 协作的重要习惯。**
