## 为什么需要专门的中文评测

主流国际榜单的题目以英文为主，模型中文能力与之相关性有限：成语、公文、古文、中文逻辑推理、本土知识问答，这些能力在 MMLU 式的翻译基准上几乎测不出来。国产模型在英文榜"隐身"、中文任务却很能打（反之亦然）的情况都很常见。中文场景选型，先看中文榜。

## OpenCompass 司南：体系最完整的开源评测

[OpenCompass](https://opencompass.org.cn/) 由上海人工智能实验室主导，是中文世界最有体系的评测项目，2.0 架构分三层：

- **CompassKit**：开源评测工具链，任何人可对任意模型（含私有模型）复现评测；
- **CompassHub**：评测数据集社区，收录 70+ 评测集；
- **CompassRank**：官方榜单，覆盖知识与考试、语言与理解、推理、代码等维度，且**中英文双语模型同榜可比**。

**怎么用：**
- **看榜**：[rank.opencompass.org.cn](https://rank.opencompass.org.cn/) 综合榜之外，重点看"分能力"雷达与明细——知识、推理、代码各维度排名差异很大，按你的核心场景挑长板；
- **复现评测**：CompassKit 以开源工具发布，可对任意模型（含私有部署模型）跑同一套数据集得到可横向比较的分数，这也是它相对闭源榜单的最大价值——结果可复现、可质疑、可审计，采购前要求供应商接受 CompassKit 复测是很实用的谈判条款；
- **找评测集**：CompassHub 收录的 70+ 数据集可单独下载，拿来构建自建评测的题库起点非常合适。

## SuperCLUE：独立第三方中文测评

[SuperCLUE](https://www.superclueai.com/) 由独立团队运营，特点是**更新勤、维度细、贴近国内动态**：

- 通用总榜之外有学科、代码、智能体、安全等专项榜；
- 长期跟踪国内外模型在中文任务上的月度变化，新模型上线后通常很快出测评；
- 报告形式友好，适合作为管理层汇报与选型佐证材料。

注意其部分深度报告为付费内容，免费榜单足够日常参考。

## 其他常见中文基准

| 基准 | 说明 |
| --- | --- |
| C-Eval / CMMLU | 中文学科知识选择题，国内引用最广，但已接近饱和，区分度下降 |
| AGI-Eval / GaoKao 类 | 模拟人类考试，直观但题目静态 |
| 各类"动态更新"榜单 | 关注是否持续换题，静态榜的污染风险同样适用于中文 |

## 使用建议

1. **双榜交叉**：OpenCompass 与 SuperCLUE 的方法论不同，结论一致时才可信。
2. **看分能力维度**，不要只看总分——你做客服还是写代码，关心的列完全不同。
3. **中文 + 英文榜都要看**：模型的中英文能力不总是同步，混合场景（如代码注释、双语客服）两边都不能瘸。
4. **能复现就复现**：OpenCompass 开源工具链 + 你自己的业务测试集，是任何榜单都替代不了的终审。
