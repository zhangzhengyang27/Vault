## 它是什么

[arXiv](https://arxiv.org/) 是 1991 年由物理学家 Paul Ginsparg 创建的预印本（preprint）平台，现由康奈尔大学维护。作者在正式投稿期刊或会议之前，先把论文上传到这里占坑与传播。AI 领域的重磅工作——从 Transformer 到 GPT 系列、Llama、DeepSeek——无一例外都在 arXiv 首发，可以说**不看 arXiv，就只能吃到二手信息**。

与期刊不同，arXiv 采用审核制而非同行评审：只检查格式与基本合规，不判断学术质量。这换来的是极快的速度：投稿后通常 1–3 个工作日即可公开。

## AI 相关的核心分类

| 分类代号 | 领域 |
| --- | --- |
| cs.CL | 计算语言学 / NLP，大模型论文的主阵地 |
| cs.LG | 机器学习，覆盖面最广 |
| cs.CV | 计算机视觉 |
| cs.AI | 通用人工智能 |
| cs.RO | 机器人学（具身智能常用） |
| stat.ML | 统计机器学习 |

一篇论文常横跨多个分类（如 cs.CL 与 cs.LG 双标）。全库累计论文已达数百万篇、每月新增上万篇，其中 AI 相关占比逐年攀升——直接刷列表是不现实的，必须靠订阅和检索。

## 怎么用

**检索**：站内搜索支持 `ti:`（标题）、`au:`（作者）、`abs:`（摘要）、`cat:`（分类）等字段组合，例如 `ti:"chain of thought" AND cat:cs.CL`。高级检索入口在 arxiv.org/search。

**追踪新论文（推荐方式）**：
- **按分类订阅 RSS**：`https://rss.arxiv.org/rss/cs.CL` 每日推送该分类全部新论文，适合配合 RSS 阅读器做每日快筛。
- **[Hugging Face Papers](https://huggingface.co/papers)**：社区按"有多少人公开表态"筛选每日亮点，密度高、噪音低，是当前最主流的 AI 论文日报替代品。
- **社交渠道**：X/Twitter 上的论文解读账号、知乎与机器之心等中文媒体的解读文章适合做补充，但注意它们有选题偏好与滞后。

**引用 API**：`export.arxiv.org/api/query?id_list=2401.00001` 返回 Atom XML，免费、无需注册、有限速。适合写脚本批量拉取元数据做文献分析。另有 OAI-PMH 接口供全量抓取。

## 局限与注意

1. **未经同行评审**：arXiv 上的结论可能被后续版本推翻甚至撤稿。引用时要注明"预印本"，关键结论等会议录用版（如 NeurIPS/ICML/ACL）发布后再确认。
2. **版本会更新**：论文有 v1、v2……多版本，重要修改（包括悄悄改动实验数字）可能发生在版本间。引用时应锁定具体版本号。
3. **AI 生成论文增多**：低质量甚至完全由模型生成的投稿正在增加，看到"惊人结果"先查作者与机构背景。
4. **中文内容少**：arXiv 几乎全英文。中文需求可配合 Aminer、智源社区等平台，但一手信息仍以英文为主。
