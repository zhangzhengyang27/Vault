## 它是什么

[Artificial Analysis](https://artificialanalysis.ai/) 是一家独立评测机构，对市面 250 余个模型（含 API 与开源模型）做持续横向测评。与 LMArena 的"人类偏好"互补，它回答的是客观问题：**这个模型多聪明、多快、多贵。**

## 三个核心维度

**1. Intelligence Index（智能指数）**
把多个客观基准（通用、编码、数学、agent 能力等）合成为一个综合分数，方法论在站点透明公开。它被大量第三方报告直接引用，已成行业通用口径之一。另有分项指数（编码、数学、视觉等）可下钻。

**2. 价格**
按官方 API 定价计算每百万 token 成本（输入/输出分开），支持按你的实际输入输出比例估算月成本——这是它最实用的功能：把"智能分数 ÷ 价格"算成性价比，同一档聪明的模型之间价差常达 5–10 倍。

**3. 速度与吞吐**
输出速度（tokens/s）、首 token 延迟（TTFT）实测数据。做对话产品时，50 tps 与 150 tps 的体验差距可能比智能分差 5 分更明显。

## 怎么用

- **选型对比工具**：在 Models 页勾选 2–4 个候选模型，并排看智能指数、价格、速度曲线。
- **价格计算**：结合自己的 prompt 长度与输出量估算真实成本，避免"按输入价算很便宜、实际输出 token 吃掉预算"的坑。
- **图像模型**：另有文生图模型的横评（质量/价格/延迟），选生图 API 时同样好使。
- **独立供应商视图**：同一开源模型的不同推理服务商（如 vLLM 系厂商）也在其对比范围，能看到"同模型不同价"的市场行情。

## 一个算账示例（数字为演示用假设）

假设你的客服应用每轮对话平均输入 3,000 token、输出 800 token，每天 10 万轮：

1. 候选 A：输入 $3 / 百万、输出 $15 / 百万 → 日成本 = 300M 输入 × $3/M + 80M 输出 × $15/M = $900 + $1,200 = **$2,100/天**；
2. 候选 B：输入 $0.5 / 百万、输出 $2 / 百万，智能指数略低 → = $150 + $160 = **$310/天**。

差距接近 7 倍。此时真正的问题变成：候选 B 在你的任务上比 A 差多少？用 200 条真实业务对话盲测一下，如果用户无感，答案就明确了。这就是"智能指数 × 价格 × 业务实测"三步决策法——Artificial Analysis 负责前两步，第三步没人能替你做。

## 局限与注意

1. **合成指数的取舍**：Intelligence Index 的权重设计必然有主观取舍，某个具体任务上的表现仍要看分项与业务实测。
2. **基准同样可能被"教"**：客观基准的题目若进入训练数据（污染），分数虚高。Artificial Analysis 会优先采用动态/私有基准，但没有任何基准绝对免疫。
3. **价格时效**：模型价格变化极快，页面数据有更新延迟，下单前以官方定价页为准。
4. **付费墙**：部分深度数据（历史数据、API 订阅）收费，免费层对多数选型场景已够用。

## 与 LMArena 配合

一个常见组合拳：LMArena 看口碑（人类偏好）→ Artificial Analysis 看性价比（客观分 + 价格 + 速度）→ 用自己的业务数据集做最终评测。三步走完，选型决策基本不会翻车。
