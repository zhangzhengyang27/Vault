开源模型迭代极快，这一篇给的是**选型方法 + 截至 2026 年 9 月的家族地图**。具体版本号请以发布时的最新为准——选型的底层逻辑比榜单名次更长效。

## 选型的四个步骤

1. **定任务**：通用对话/代码/长文档/多模态/端侧——不同榜单各有擅长；
2. **定约束**：显存预算（第 2 篇）、语言（中文权重？）、许可（商用条款逐个看）；
3. **初选 2-3 个候选**：按家族口碑与社区生态（能不能装、教程多不多、量化版本全不全）；
4. **用你自己的评测集定**（本站 RAG 库第 9 篇的方法）：30-50 个真实任务盲测，半天出结论。**榜单只是初筛，你的评测集才是裁判。**

## 主流家族地图（截至 2026-09）

| 家族 | 出品方 | 定位与口碑 |
| --- | --- | --- |
| **Qwen 系列** | 阿里 | 全尺寸覆盖最全（0.5B 到旗舰 MoE），中英双语强，多模态（Qwen-VL）与代码变体齐全，社区生态与量化版本最完善，商用友好——**多数中文场景的默认起点** |
| **DeepSeek 系列** | 深度求索 | 推理与代码能力突出，MoE 架构性价比高，API 定价激进；开源版本允许本地部署，蒸馏版给低资源场景留了入口 |
| **GLM 系列** | 智谱 | 中文综合能力强，学术社区活跃，全尺寸+多模态布局 |
| **Llama 系列** | Meta | 全球生态最大，英文场景标杆，中文能力弱于国产第一梯队 |
| **Mistral 系列** | Mistral AI | 欧系代表，小参数效率见长，Apache 系许可友好 |
| **Kimi/月之暗面等开源动作** | 各家 | 长文本与推理方向的开源版本，按需关注 |

**专项候选**：代码方向（Qwen-Coder、DeepSeek 系蒸馏码模型）；多模态（Qwen-VL、GLM-4V、InternVL 等）；端侧小模型（Qwen 小尺寸、Phi 系、Gemma 系）；推理增强（各家 R1/o1 风格的推理模型，输出带思考链，质量高但 token 消耗大）。

## 许可：别最后一步才看

- Apache-2.0 / MIT：商用最省心；
- 自有"社区许可"（如 Llama 系）：多数允许商用但有附加条款（月活门槛、品牌规范），逐条读；
- 研究许可：不可商用，避开。

## 中文场景的三个务实提醒

1. **中文第一梯队**（Qwen/DeepSeek/GLM）与旗舰闭源的差距在多数业务任务上已不大，且中文理解与本地化表达常有优势；
2. **蒸馏版/小参数版先行验证**：先跑小杯确认"任务需要多大模型"，再上大杯——很多人直接上最大杯，结果发现 14B 就够了（省钱 5 倍）；
3. **关注"推理模型"的使用成本**：R1 风格模型输出思考链，质量高但 token 消耗数倍——简单任务反而该用非推理模型，按任务路由（第 8 篇）。

## 版本更新怎么跟

开源模型月月出新。跟进策略：**锁版本上线**（生产不追新），季度性评估新版本（用同一评测集盲测对比），有实质提升才升级。工具链（第 4 篇）的稳定比模型的新潮更重要。
