模型排行榜是选型的起点，也是营销的主战场。2025 年 3 月，曾经的开源模型权威榜 Hugging Face Open LLM Leaderboard 因基准数据污染（考题进了训练集，分数失真）宣布归档——这个事件之后，"怎么读榜"本身成了一门必修课。以下是六个经过验证的原则。

## 原则一：交叉验证，拒绝单一来源

任何单一榜单都有偏差：LMArena 偏好"讨喜的风格"，客观基准可能被污染，厂商发布会自报的分数更只挑对自己有利的口径。可信的结论至少需要**两个方法不同的来源**相互印证：人类偏好榜（LMArena）+ 客观横评（Artificial Analysis / HELM / OpenCompass）+ 真实用量榜（OpenRouter rankings）是当前最好的三角组合。

## 原则二：看任务子榜，不看总榜

总榜第一名在你的任务上可能排不进前十。写代码看编码竞技场与 SWE-bench，做检索看 MTEB 的 Retrieval 列，中文场景看 OpenCompass 中文榜。总榜的意义只是初筛。

## 原则三：看置信区间与样本量

有统计素养的榜单（LMArena、HELM）都公布置信区间。区间重叠的两个模型，名次差异就是噪音；样本量过小的对比（比如某新模型的投票数只有老牌模型的十分之一）本身就不成熟。警惕一切不带误差范围的"精确排名"。

## 原则四：优先动态基准，警惕静态基准

静态基准（题目固定：MMLU、C-Eval、HumanEval…）的题目迟早进入训练数据，分数随时间通胀。更可信的是：
- **动态基准**：持续换新题，如 LiveBench、LiveCodeBench；
- **私有测试集**：评测集不公开，如 SWE-bench Verified 的一部分口径、HELM 的部分场景；
- **人类实时对战**：LMArena 式实时出题。

看到模型在三年前的静态基准上"刷新纪录"时，默认打折。

## 原则五：区分官方自报与独立复测

厂商发布会的分数是自报口径：可能选了对自己的评测版本、prompt、采样参数。独立机构（HELM、Artificial Analysis、OpenCompass）用统一管线复测的数字才有可比性。两者差距大本身就是信号。

## 原则六：智能只是三维之一

生产选型的完整函数是：

```
总成本 = f(质量, 价格, 延迟/吞吐, 上下文长度, 合规, 稳定性)
```

一个智能分高 5% 但价格贵 3 倍、速度慢一半的模型，对多数业务是错误选择。Artificial Analysis 的性价比视图就是为这个决策设计的。

## 一页速查

| 信号 | 健康的榜 | 危险的信号 |
| --- | --- | --- |
| 来源 | 多个独立机构互相印证 | 只有一家厂商自报 |
| 范围 | 有任务子榜、语言子榜 | 只有一个华丽总分 |
| 统计 | 有置信区间与样本量 | "领先 0.3 分"式精确到小数 |
| 时效 | 动态换题或私有测试集 | 多年不变的静态考卷 |
| 利益 | 独立运营、方法论公开 | 榜单运营方同时卖模型 |
