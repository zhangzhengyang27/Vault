HTML 实体转义工具

模式:

这个工具做什么:

这个 HTML 实体工具帮助你在特殊字符与对应 HTML 实体之间相互转换。它有两种工作模式:

转义模式(默认):

转义模式:把特殊字符转换为 HTML 实体。当你需要在网页上展示包含 HTML 语法的代码或文本、又不希望它被当作真实 HTML 解析时,这个模式很有用。

  • & 转换为 &amp;
  • < 转换为 &lt;
  • > 转换为 &gt;
  • " 转换为 &quot;
  • ' 转换为 &#39;

反转义模式:

反转义模式:把 HTML 实体还原为原始字符。当你拿到一段 HTML 编码过的文本、需要解码阅读或进一步处理时使用。

支持的格式:

  • 命名实体: &amp; → &, &lt; → <, &gt; → >, &quot; → "
  • 十进制数字实体: &#34; → ", &#160; → non-breaking space
  • 十六进制数字实体: &#x22; → ", &#xA0; → non-breaking space

本工具支持全部标准 HTML 实体以及任意数字字符引用。

使用方法:先选择模式(转义或反转义),再把文本粘贴进输入框,输出框会自动出现转换结果,点击「复制到剪贴板」按钮即可带走。
