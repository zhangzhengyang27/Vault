// 04 · 关于我

一人工作室，十年游戏梦

曾是一名全栈工程师，2019 年裸辞开始做独立游戏。白天写引擎、调光照、录音效，晚上回复玩家评论、 改平衡性数值。我相信「小而锋利」：与其做平庸的大作，不如把一个小循环做到让人上瘾。

日常栈：Unity · C# · Godot · Rust · GLSL · WebGL · FMOD。最近在折腾把经典 Roguelike 机制移植到 3D 世界，并持续用博客记录实验过程。
