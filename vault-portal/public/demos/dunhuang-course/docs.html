系统架构说明

本门户为纯静态多页 Web 应用，无需后端服务即可公开访问；AI 讲解员与语音朗读在客户端完成，Ai 视觉/音乐资源预生成后统一存放。

技术栈

原生 HTML5、CSS3 与 JavaScript（无构建步骤），交互地图采用 Leaflet + OpenStreetMap 底图（经 CSS 滤镜作古董风处理）。视觉资产由文生图生成，背景乐由文生音乐生成，章节短片优先复用公开版权视频、缺失时降级为封面动效；语音朗读与讲解员播报使用浏览器 Web Speech Synthesis API。

数据与资源约定

全部种子内容集中在 assets/js/data.js，以 window.DUNHUANG 暴露：8 个章节（含讲稿与壁画细节）、30 个城市、28 件文物、讲解员知识库。生成的图片统一存于 assets/images/（chapter-01..08、relic-01..34、hero、avatar）；背景乐为 assets/media/bgm.mp3，章节短片为 assets/media/video-<id>.webm。图片加载失败时自动回退到风格化 SVG 占位，保证全站完整可访问。

视觉规范说明

整体追求「博物馆级」中文留白与丝滑过渡：暗金做标题描金与高光、石青做结构与纹理、赭石做强调与节点，墨底用于夜间剧场式开场，米色纸本用于长文阅读。

字体与排版

标题与描金文字使用中文衬线字族（宋体 / Source Han Serif SC），正文使用无衬线中文（苹方 / 思源黑体）。关键标题采用线性渐变描金 + 细微字描边，营造鎏金质感。正文行高约 1.9、字距 0.02em，段落间留白充足。

动画

过渡统一采用缓动曲线 cubic-bezier(.22,.61,.36,1)。首页实现视差滚动、飞天粒子上升、丝路轨迹虚线流动；章节卡片悬停平移与轻微 3D 倾斜；文物卡片 360° 翻转；讲解员流式打字与光标闪烁。所有动画均为 GPU 友好的 transform/opacity，避免卡顿。
