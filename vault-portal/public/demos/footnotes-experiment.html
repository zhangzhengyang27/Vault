脚注的魔力

这里演示的是一个交互式脚注系统,与示例文章所用方案类似。当你写到需要补充背景或引用出处的内容时,就可以加一条脚注1.

脚注的价值在于补充信息而不打断正文节奏:可以放引用、做澄清,或补充有趣的题外话2.

最好的脚注是提供了上下文、却不强迫你阅读的脚注——它服务于好奇的读者,而不是路过的读者。

也可以用脚注来做技术性澄清3. And unlike traditional print footnotes, these are interactive – try hovering over or clicking on the footnote references!

工作原理

这套系统用 HTML、CSS 和一点 JavaScript 让脚注变得可交互。关键组成部分:

  1. 正文中的脚注引用,带正确的 ID 与 ARIA 角色
  2. 页面底部对应的脚注区块
  3. 与引用交互时展示脚注内容的 JavaScript

标记通过规范的 ARIA 角色遵循无障碍标准。你甚至可以用链接在正文与脚注之间往返4.
